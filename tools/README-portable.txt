P3R SAVE TRANSFER
=================

Перенос сохранений Persona 3 Reload из версии Microsoft Store / Xbox Game Pass
в Steam. Работает без установки, без Python и без прав администратора.

----------------------------------------------------------------------------
КАК ЗАПУСТИТЬ
----------------------------------------------------------------------------

1. Распакуй ВСЮ папку (не только exe) в любое место: рабочий стол, диск D:,
   флешку. Путь может содержать пробелы и русские буквы.
2. Двойной клик по P3R-Save-Transfer.exe.
3. Windows SmartScreen может показать синее окно "Windows защитила ваш
   компьютер": файл не подписан (сборка сделана локально, сертификата нет).
   Нажми "Подробнее" -> "Выполнить в любом случае".
   Антивирус может ругаться на свежесобранный exe - это ложное срабатывание
   PyInstaller; при сомнениях используй консольную версию или сборку из исходников.

Закрой игру и приложение Xbox перед конвертацией: занятые файлы не
перезапишутся.

----------------------------------------------------------------------------
ЧТО ДЕЛАТЬ (3 КЛИКА)
----------------------------------------------------------------------------

1. "Найти автоматически" - утилита сама смотрит
   %LOCALAPPDATA%\Packages\SEGAofAmericaInc.L0cb6b3aea_s751p9cej88mt\
   SystemAppData\wgs
   Если сохранений нет - нажми "Выбрать папку..." и укажи папку wgs вручную
   (или перетащи её в окно).
2. Проверь список: отметь нужные сохранения. Слот, дата, уровень и игровое
   время видны в таблице. "—" значит, что поле не удалось прочитать, - это не
   мешает конвертации.
3. Нажми "Конвертировать". Папка Steam определяется сама
   (%APPDATA%\Sega\P3R\Steam\<SteamID64>). Если файлы уже есть, появится
   подтверждение перезаписи. После завершения - "Открыть папку".

Горячие клавиши: Ctrl+O - выбрать папку, F5 - обновить, Ctrl+Enter -
конвертировать, Esc - отмена/закрыть.

----------------------------------------------------------------------------
ГДЕ ЛЕЖАТ ФАЙЛЫ
----------------------------------------------------------------------------

Microsoft Store / Game Pass:
  %LOCALAPPDATA%\Packages\SEGAofAmericaInc.L0cb6b3aea_s751p9cej88mt\
  SystemAppData\wgs\<XboxUserID>\<GUID>\<GUID>\<файл без расширения>

Steam:
  %APPDATA%\Sega\P3R\Steam\<SteamID64>\SaveDataNNN.sav

Вставить путь в проводник: Win+R, вставь строку с %LOCALAPPDATA% или %APPDATA%.

Если сохранений нет на диске: они ещё в облаке Xbox. Установи игру из
Microsoft Store на этом ПК, войди в СВОЙ аккаунт, запусти её один раз и дай
синхронизировать сохранения, затем закрой игру. Утилита не логинится в
аккаунты и не работает с облаком.

----------------------------------------------------------------------------
БЕЗОПАСНОСТЬ И ОГРАНИЧЕНИЯ
----------------------------------------------------------------------------

- Исходные сохранения только читаются: утилита ничего не пишет в wgs.
- Перед записью создаётся папка _p3r_backup_<дата-время> с копиями файлов
  и manifest.json (размер + SHA-256).
- Достижения Game Pass в Steam НЕ переносятся - это ожидаемо.
- Настройки хранятся в config.json рядом с exe; если папка только для чтения -
  в %LOCALAPPDATA%\P3R-Save-Transfer\config.json.
- Утилита не требует интернет, не ставит службы, не пишет в реестр.

----------------------------------------------------------------------------
КОНСОЛЬНАЯ ВЕРСИЯ
----------------------------------------------------------------------------

p3r-save-transfer-cli.exe повторяет CLI:

  p3r-save-transfer-cli.exe scan
  p3r-save-transfer-cli.exe convert-all --wgs "%LOCALAPPDATA%\Packages\SEGAofAmericaInc.L0cb6b3aea_s751p9cej88mt\SystemAppData\wgs" --out-dir "%USERPROFILE%\p3r_out"
  p3r-save-transfer-cli.exe verify "%USERPROFILE%\p3r_out\SaveData001.sav"
  p3r-save-transfer-cli.exe --help

----------------------------------------------------------------------------
ПРОВЕРКА ЦЕЛОСТНОСТИ
----------------------------------------------------------------------------

PowerShell, хэши до и после (должны совпасть):

  Get-ChildItem -Recurse -File "$env:LOCALAPPDATA\Packages\SEGAofAmericaInc.L0cb6b3aea_s751p9cej88mt\SystemAppData\wgs" |
      Get-FileHash -Algorithm SHA256 | Format-Table Hash, Path
