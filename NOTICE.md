P3R Save Transfer Tool is an unofficial community utility. It is not affiliated
with, endorsed by, or supported by Atlus, SEGA, Microsoft or Valve. Persona 3
Reload and all related names and trademarks belong to their respective owners.

What this project contains:

- original source code, written for this tool;
- two SIL Open Font License typefaces (Oswald, Inter), renamed static instances,
  with their licence texts in `assets/fonts/`;
- UI screenshots of this tool itself.

What this project does **not** contain and will not accept:

- game assets, models, textures, audio, fonts or any other files extracted from
  Persona 3 Reload;
- save files or fragments of save files belonging to anyone;
- anything that allows playing the game without a licence, bypasses DRM, or
  interferes with store entitlements and achievements.

Intended use: converting **your own** save files between copies of the game you
own (Microsoft Store / Xbox Game Pass and Steam).

Beta software: bugs are possible. The tool creates a backup of the destination
folder by default and only ever reads the Microsoft Store save folder, but keep
your own backups anyway.
